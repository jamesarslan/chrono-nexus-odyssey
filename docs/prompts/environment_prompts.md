## Notes for Hunyuan3D-2.1 Workflow
- Props and items work best with single clear reference images
- Use isometric or front views for best 3D reconstruction
- Export as GLB, import directly into Godot
- Set appropriate collision shapes in Godot after import
- Environment pieces can be composed in Godot scene editor
